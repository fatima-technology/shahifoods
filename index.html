      Cloud sync (Firebase)

      Keeps your rate list, packing, photos, logos, settings and last stock report in your own Firebase project, so the same data opens on your phone and laptop. Data stays in this browser too, so it works offline.

      Not connected

      One-time Firebase setup
      1. Go to console.firebase.google.com → Add project.
      2. Build → Authentication → Get started → enable Email/Password.
      3. Authentication → Settings → Authorized domains → add fatima-technology.github.io.
      4. Build → Firestore Database → Create database → then open the Rules tab and paste these rules → Publish:
      rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == uid; } } }
      1. Project settings (gear icon) → Your apps → Web (</>) → register app → copy the firebaseConfig part and paste it in box 1.
      2. Create an account in box 2. Use the same email and password on your other phone or laptop.
